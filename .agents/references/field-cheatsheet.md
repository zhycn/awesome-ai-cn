# 字段速查与写作规则

摘自 `docs/CONVENTIONS.md`（权威来源）与 `config/schema.json`（机器定义），供技能快速查阅。本表是速查摘要，与两者冲突时以后两者为准。

## 字段

| 字段       | 必填 | 类型/枚举                                     | 说明                      |
| ---------- | ---- | --------------------------------------------- | ------------------------- |
| `id`       | ✅   | 小写连字符 slug，≤64 字符                     | 全局唯一，**创建后不改**  |
| `name`     | ✅   | 字符串，1–40 字符                             | 保留官方大小写            |
| `url`      | ✅   | `http(s)://`，≤300 字符                       | 主入口，无追踪参数        |
| `desc`     | ✅   | 6–60 字                                       | 一句话中文简介            |
| `tags`     | ⬜   | 数组，1–3 个，受控词表                        | 没有合适的就整条省略      |
| `pricing`  | ✅   | `free` / `freemium` / `paid` / `open-source`  |                           |
| `status`   | ✅   | `active` / `beta` / `deprecated` / `archived` | 后两者不展示但仍保留      |
| `added`    | ✅   | `YYYY-MM-DD`                                  | 收录日期                  |
| `vendor`   | ⬜   | 字符串                                        | 归属机构，未知省略        |
| `lang`     | ⬜   | `zh` / `multi` / `en`（默认 `zh`）            |                           |
| `featured` | ⬜   | `true`                                        | 每主题最多 3 条，不改位置 |
| `access`   | ⬜   | `direct`（默认）/ `proxy`                     | `proxy` 显示 🌐           |

> 已知问题：`docs/CONVENTIONS.md` 第 3 节列有 `links: {repo, docs}` 字段，但 `config/schema.json` 尚未定义（填了会被 `validate` 拦为未知字段）。需要时先走 `change-management` 流程给 schema 增补，再使用。

## desc 写作

- 一句话说清「是什么 + 凭什么值得收」，无第二句
- 陈述句，不加句号，不感叹，单行
- 禁营销词：最强、颠覆、革命性、一站式、神器
- ❌ `LangChain 是一个 LLM 编排框架` → ✅ `LLM 应用编排框架，插件生态完整`（不要重复名称开头）

## tags 纪律

标签只回答：**这个项目有什么是别的字段推不出来的？**

- 只用 `config/tags.json` 词表；1–3 个，宁少勿滥
- 禁占位词：`API` `网页版` `开源` `免费` `付费` `平台` `模型`（可由 pricing/lang/主题推出）
- 主题内人人皆有的能力不打标签
- 只表达「能力/形态/归属」，不表达评价（禁 `好用` `推荐`）

## 常见报错对照

| 报错             | 原因                                   |
| ---------------- | -------------------------------------- |
| `未知字段 'xxx'` | 字段拼错或新字段未进 schema            |
| `id 全局重复`    | 同一项目收了两次                       |
| `链接重复`       | 同一入口被收录两次（忽略尾斜杠/锚点）  |
| `长度超限`       | desc > 60 字 / name > 40 字 / tags > 3 |
| `取值非法`       | 枚举字段或标签不在词表内               |
